# Nook
RUNTEQ卒業制作アプリ（第二案）

## 1. サービス概要

- このサービスはどんなサービスか
子育て中の人の、子育てに関してちょっと知りたいことや、子供の成長を気遣わず共有したい時にゆるく繋がれるアプリ

- 誰の、どんな課題を、どう解決するか
「子育て中の人」の「ゆるく繋がりたいけど気は使いすぎたくないという思い」を「好きな時に安心してゆるく繋がれるコミュニティの場を作ることで解決する」

## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

このアイデアの元になった

- いつ<br>
	- 10〜15分くらいの短い隙間時間をほっこりできるような時間にしたい時
	- 子育てについてゆるく語り合いたい時
	- 子育てについてちょっと聞いてみたいことがある時
	
- どんな状況で<br>
	- 子育て中

- どんな気持ちになったか<br>
	- 他の子育て中の人とゆるく繋がりたい 
	- みんなの「うちはこうしてるよ」を知りたい
	- 安心して子育てについての情報を見たい

- 具体的なエピソード<br>
子育て中の友人と話している時に、以下のようなニーズがあることがわかった。
	- 仕事も家事育児もしているとまとまった時間は作れないけど、短い時間でほっこりした気持ちになれるようなコミュニティの場が欲しい。
	- 子供の成長で嬉しかったことや自慢したくなるようなことは、親族以外には気を遣って話しづらい。気兼ねなくお互いの子供の成長を一緒に喜び合えるような場があると嬉しい。
	- ちょっとした子育てのコツやライフハック情報をシェアしたい。
	- SNSでは「こうすべき」「子育てのNG」など不安になる投稿も多くあるけど、どうしても目に入ってしまい、初めての子育てだと流されてしまうこともあるから不安を煽るものではなくて安心して見れるものが欲しい。
	- 子供の発達に関することなど、プロに相談するほどではないけど「みんなどうしてるのかな」といったライトな疑問を聞きたい。
	- 完全匿名性の質問機能がほしい。アカウントから遡って矛盾を指摘されて嫌な気持ちになったことがある。
	- リアクション数が表示されないコミュニティがいい。

## 10. 技術スタック（手段としての技術）

### 10-1. 使用予定の技術

- フレームワーク：Ruby on Rails
- DB：PostgreSQL
- デプロイ先：Render
- 使用予定ライブラリ：
	- Devise（ユーザー認証）
	- Ransack（検索機能）
	- CarrierWave（画像アップロード）
	- MiniMagick（画像リサイズ）
	- Kaminari（ページネーション）


---

### 10-2. 技術選定の理由

- なぜこの技術を使うのか
	- Ruby on Railsは、投稿・コメント・認証などコミュニティサイトで必要となる機能を効率よく実装できるため採用しました。
	- データベースにはRailsとの親和性が高く、本番環境でも広く利用されているPostgreSQLを使用します。
	- デプロイ先にはRenderを利用し、Webアプリケーションを公開できる環境を構築します。
	- 画像投稿機能には、RUNTEQのカリキュラムで実装経験のあるCarrierWaveを利用する予定です。
	- 検索機能にはRansackを利用し、投稿を探しやすいアプリを目指します。

- 今回チャレンジしたい点
	- コメントを中心としたコミュニティ機能の実装
	- 使いやすいUI・UXの設計
	- 画像投稿機能の実装
	- 投稿検索機能の実装
	- リアクション機能の実装

- 不安な点
	- 投稿・コメント・リアクションなど複数のモデルが関連するため、データベース設計が複雑になる可能性があること
	- コミュニティサービスでは投稿内容の管理やバリデーションも考慮する必要があること
	- 本リリースで予定している検索機能や画像投稿機能を、開発期間内に完成させられるか
